## The data

Twelve hourly readings, all `VALID`, all inside `−90 .. +60`:

| 00:00 | 01:00 | 02:00 | 03:00 | 04:00 | 05:00 | 06:00 | 07:00 | 08:00 | 09:00 | 10:00 | 11:00 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 0.0 | 0.1 | 0.1 | 0.2 | 0.4 | 0.8 | 1.6 | 3.2 | 6.4 | 12.8 | 25.6 | 51.2 |

Each round discards exactly the largest value:

| Round | Mean | Deviation | Discarded |
|---|---|---|---|
| 1 | 8.533 | 15.437 | 51.2 |
| 2 | 4.655 | 7.972 | 25.6 |
| 3 | 2.560 | 4.122 | 12.8 |
| 4 | 1.422 | 2.134 | 6.4 |
| 5 | 0.800 | 1.105 | 3.2 |

Five rounds, `P-02` = 5, **still not converged**. The summary is published anyway:

| Output | Value |
|---|---|
| `retained_count` / `rejected_count` | **7** / **5** |
| `mean_temperature` | **0.5 °C** |
| `min_temperature` / `max_temperature` | **0.0 °C** / **1.6 °C** |
| `frost_episodes` | **none** |
| `quality_label` | **`SUSPECT`** |

## Why the case exists

Because a bounded loop has **two** exits, and only one of them is obvious.

`RG-030` stops when a round discards nothing. That is the exit everybody implements. The
other one — the round counter reaching `P-02` — leaves the implementer with a choice
nobody made for them: raise an error, return nothing, keep looping, or publish. Four
implementers, four answers, and none of them written down.

The specification chose: **the summary is published, labelled `SUSPECT`.** Non-convergence
is deliberately absent from the error table of §9 — it is a result to be qualified, not a
failure to be raised, because a station whose readings will not settle is exactly the
station a climatologist wants to see rather than not receive.

This case was **built** to reach that exit. A doubling sequence keeps every round's largest
value more than two deviations from the mean, so each round removes exactly one and the
process needs eleven rounds where it has five. No natural day of weather does this.

> **The values used to be 0, 1, 2, … 1024 °C.** Those rounds were arithmetically correct
> and could never happen: `RG-010` discards anything above 60 °C, so `RG-030` would have
> seen seven readings, not twelve, and converged on the first round. The sequence is now
> scaled by a tenth, which changes nothing structurally — the clipping compares deviations
> to a **multiple of the deviation**, so it is invariant under scale — and every reading is
> now physically possible. The defect surfaced when the code was written against the
> stated data and the published rounds did not appear.

## What it does not test

| | |
|---|---|
| Convergence after several rounds | It converges after none. CT-01 converges in two. Nothing exercises "converged on round 4" |
| Frost episodes | Every retained reading is `≥ 0.0 °C`, so `RG-050` produces an empty sequence — worth having, but it tests the empty case, not the grouping |
| [`P-04`](../spec/SPEC-WTH-001.en.md#p-04) | The mean is 0.4571…, which rounds to 0.5 under either mode |
| The boundary of `P-02` | The loop runs out at 5. **No case converges on exactly round 5**, where one round fewer would flip the label from `ACCEPTABLE` to `SUSPECT` |
