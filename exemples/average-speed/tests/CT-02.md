# CT-02 — Equal durations

| | |
|---|---|
| **Case** | `CT-02` |
| **Specification** | [SPEC-SPD-001 §10](../spec/SPEC-SPD-001.en.md#ct-02--equal-durations) v1.1.0 |
| **Reference data** | [`reference-data.csv`](../code/src/test/resources/reference-data.csv), line `CT-02` |
| **Discriminating** | **No — and that is the point of the case** |

## What it covers

| Item | |
|---|---|
| [`RG-010`](../spec/SPEC-SPD-001.en.md#rg-010--duration-of-one-leg) | Duration of one leg |
| [`RG-020`](../spec/SPEC-SPD-001.en.md#rg-020--journey-totals) | Journey totals |
| [`RG-030`](../spec/SPEC-SPD-001.en.md#rg-030--average-speed) | Average speed |

It covers them in the bookkeeping sense: the code runs through all three. It **verifies**
none of them, because a wrong implementation of `RG-030` returns the same answer.

## The data

| Leg | Distance | Speed | Duration |
|---|---|---|---|
| 1 | 30 km | 30.0 km/h | 1.000000 h |
| 2 | 60 km | 60.0 km/h | 1.000000 h |

```
total_distance = 30 + 60           = 90 km
total_duration = 30÷30 + 60÷60     = 2 h
average_speed  = 90 ÷ 2            = 45.0 km/h
```

The arithmetic mean of the speeds — the wrong implementation — gives `(30 + 60) ÷ 2 = 45.0`
**as well**.

**Expected: `average_speed` = 45.0 km/h.**

## Why the case exists

Because the two methods coincide **exactly when all legs take the same time**, and that is
worth showing rather than asserting.

Kept in the reference set, this case does a job no passing case can do: it makes visible
that *a green suite is not a proof*. Three of the six cases here — CT-02, CT-03 and CT-04 —
are passed by an implementation that averages the speeds. Only CT-01 and CT-06 reject it.
Remove those two and the suite still runs green while the published number is wrong on
almost every real journey.

The [test report](../reports/TEST-REPORT.md) says so case by case, in the same column as
the result: *does not discriminate — the naive mean gives the same answer*. A case that
cannot fail for the reason you care about should say so on the report, not in a comment
someone will delete.

## What it does not test

Everything CT-01 tests. The two documents are the same shape on purpose: same number of
legs, same two speeds, one distance changed. **The only difference is whether the legs take
the same time**, and that single difference decides whether the case is worth anything as a
detector.
